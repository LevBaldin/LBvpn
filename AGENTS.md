# Repository Instructions

## Language

Use English for all repository content, code comments, commit messages, and pull request descriptions. Communicate with the user in Russian unless requested otherwise.

## Git Workflow

- Develop on `dev`. Do not merge into `main` without a user request.
- Create a separate local commit for each completed feature, fix, or other coherent change after appropriate validation.
- Use concise English commit messages with prefixes such as `feat:`, `fix:`, `docs:`, or `chore:`.
- Do not leave completed work uncommitted unless the user explicitly asks for it.
- Stage only files belonging to the current change. Preserve unrelated user changes.
- Never commit secrets, private keys, or active VPN configurations.
- Report the resulting commit hash and validation outcome to the user.
- Distinguish local commits from publication to GitHub. Push only when authorized by the user or the agreed task workflow.
